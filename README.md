# Lab 6 — Routing et navigation

Avec Node.js 22 (22.12 ou plus récent sur cette version majeure), exécuter `npm install`, puis `npm start`. Ouvrir http://localhost:4200.

Le catalogue local fournit les données d’exemple pour pratiquer le routage. La recherche des étudiants reste dans le paramètre `search` de l’URL. La garde de démonstration protège `/admin`, et le tableau de bord permet de changer le rôle simulé. Une URL inconnue affiche la page 404.
